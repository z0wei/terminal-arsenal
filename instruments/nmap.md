# 🗺️ Nmap — максимальная шпаргалка

> **Что такое Nmap:** Nmap (Network Mapper) — это мощный инструмент с открытым исходным кодом для обнаружения сети, аудита безопасности и сканирования уязвимостей. Он позволяет быстро определять живые хосты, открытые порты, работающие сервисы, операционные системы и потенциальные риски безопасности в сети.

---

## 📌 1. Базовый синтаксис

```bash
nmap [параметры] <цель>
```

---

## 🎯 2. Выбор цели (Target Selection)

| Команда | Описание |
| :--- | :--- |
| `nmap 192.168.1.1` | Сканирование одного IP |
| `nmap domain.com` | Сканирование одного домена |
| `nmap 192.168.1.1-254` | Сканирование диапазона IP |
| `nmap 192.168.1.0/24` | Сканирование подсети |
| `nmap -iL targets.txt` | Сканирование из списка хостов в файле |
| `nmap -n <target>` | Отключить DNS-разрешение (ускоряет сканирование) |
| `nmap -R <target>` | Включить DNS-разрешение для всех хостов |
| `nmap --exclude <host>` | Исключить хост из сканирования |

---

## 🔍 3. Обнаружение хостов (Host Discovery)

| Команда | Описание |
| :--- | :--- |
| `nmap -sn <target>` | Ping-сканирование (только обнаружение хостов, без сканирования портов) |
| `nmap -Pn <target>` | Пропустить обнаружение хостов (сканировать как живые) |
| `nmap -PS<port> <target>` | TCP SYN ping на указанный порт |
| `nmap -PA<port> <target>` | TCP ACK ping |
| `nmap -PU<port> <target>` | UDP ping |
| `nmap -PE <target>` | ICMP Echo ping |
| `nmap -PP <target>` | ICMP Timestamp ping |
| `nmap -PM <target>` | ICMP Netmask ping |
| `nmap -sn -PS21,22,25,80,445,3389,8080 -PU137,138 10.0.2.0/24` | Комбинированный хост-дискавери |

## 🚪 4. Сканирование портов (Port Scanning)

### 4.1. Типы TCP-сканирования

| Флаг | Название | Описание |
| :--- | :--- | :--- |
| `-sS` | SYN Scan (Stealth) | Полуоткрытое сканирование, не завершает рукопожатие. **По умолчанию** для root |
| `-sT` | TCP Connect Scan | Полное TCP-рукопожатие. Используется без root-прав |
| `-sA` | ACK Scan | Отправляет ACK-пакеты для определения фильтров |
| `-sF` | FIN Scan | Отправляет FIN-флаг (обходит некоторые файрволы) |
| `-sN` | Null Scan | Отправляет пакеты без флагов |
| `-sX` | Xmas Scan | Устанавливает FIN, URG и PSH флаги |
| `-sW` | Window Scan | Использует TCP Window-поле |
| `-sM` | Maimon Scan | FIN/ACK сканирование |

### 4.2. UDP-сканирование

| Флаг | Описание |
| :--- | :--- |
| `-sU` | UDP-сканирование |
| `-sU -p 53,161,67,69` | Сканирование распространённых UDP-портов (DNS, SNMP, DHCP, TFTP) |

### 4.3. Выбор портов

| Флаг | Описание |
| :--- | :--- |
| `-p 80,443` | Сканирование только указанных портов |
| `-p 1-65535` | Сканирование всех портов |
| `-p-` | Сокращение для всех портов (1-65535) |
| `-p U:53,T:21-25,80` | Смешанное сканирование UDP и TCP портов |
| `-F` | Быстрое сканирование (только 100 самых популярных портов) |
| `--top-ports 200` | Сканирование 200 самых популярных портов |

## 🖥️ 5. Обнаружение версий и ОС

| Команда | Описание |
| :--- | :--- |
| `nmap -sV <target>` | Определение версий сервисов |
| `nmap -sV --version-light <target>` | Лёгкое определение версий (быстрее) |
| `nmap -sV --version-all <target>` | Полное определение версий (медленнее) |
| `nmap -sV --version-intensity 8 <target>` | Интенсивность 0-9 (9 — максимальная) |
| `nmap -O <target>` | Определение ОС |
| `nmap -O --osscan-guess <target>` | Агрессивное угадывание ОС |
| `nmap -A <target>` | **Всё в одном:** ОС + версии + скрипты + traceroute |

## 📜 6. Nmap Scripting Engine (NSE)

### 6.1. Основные флаги

| Флаг | Описание |
| :--- | :--- |
| `-sC` | Запуск стандартных (default) скриптов |
| `--script <script>` | Запуск конкретного скрипта |
| `--script <category>` | Запуск всех скриптов из категории |
| `--script-help <script>` | Показать справку по скрипту |
| `--script-updatedb` | Обновить базу скриптов |

### 6.2. Основные категории скриптов

| Категория | Описание |
| :--- | :--- |
| `default` | Безопасные скрипты по умолчанию (запускаются с `-sC`) |
| `safe` | Безопасные скрипты (не наносят вред) |
| `unsafe` | Потенциально опасные скрипты |
| `enumeration` | Сбор информации |
| `auth` | Проверка аутентификации |
| `broadcast` | Обнаружение хостов в локальной сети |
| `brute` | Брутфорс паролей |
| `exploit` | Эксплуатация уязвимостей |
| `discovery` | Обнаружение сервисов и хостов |
| `vuln` | Поиск уязвимостей |

### 6.3. Примеры NSE-скриптов

```bash
# Стандартные скрипты
nmap -sC <target>

# HTTP-скрипты
nmap --script http-enum <target>
nmap --script http-headers <target>
nmap --script http-methods <target>

# FTP-скрипты
nmap --script ftp-anon <target>

# SMB-скрипты
nmap --script smb-enum-shares <target>
nmap --script smb-os-discovery <target>

# Поиск уязвимостей
nmap --script vuln <target>

# Специфический скрипт
nmap --script http-put <target>

# Поиск скриптов
ls -l /usr/share/nmap/scripts/ | grep http
find /usr/share/nmap/scripts/ -name "*.nse" | wc -l   # количество скриптов
```

## 🛡️ 7. Обход файрволов и IDS/IPS (Evasion)

### 7.1. Основные техники

| Команда | Описание |
| :--- | :--- |
| `-Pn` | Пропустить обнаружение хостов (если хост не отвечает на ping) |
| `-f` | Фрагментация пакетов |
| `--mtu <size>` | Установить MTU для фрагментации |
| `-D RND,RND,ME` | Использовать случайные декои |
| `-D 10.10.10.1,10.10.10.2,ME` | Указать конкретные декои |
| `-S <IP>` | Спуфинг исходного IP-адреса |
| `-g <port>` | Использовать фиксированный исходный порт |
| `--spoof-mac <MAC>` | Спуфинг MAC-адреса |
| `--proxies <proxy>` | Использовать прокси |
| `--data-length <num>` | Добавить случайные данные к пакетам |
| `--scan-delay <time>` | Задержка между пакетами |
| `--max-rate <rate>` | Ограничить скорость отправки |
| `-6` | Использовать IPv6 (часто менее мониторится) |
| `-sI <zombie>` | Idle Scan (Zombie-сканирование) |

### 7.2. Примеры обхода

```bash
# Базовый обход
nmap -Pn -f <target>

# С декоями
nmap -sS -Pn -D RND,RND,ME -F <target>

# С прокси
nmap -sS -Pn --proxies http://proxy:8080 <target>

# С задержкой
nmap -sS --scan-delay 1s --max-rate 5 <target>
```

## ⏱️ 8. Настройка производительности (Timing)

### 8.1. Timing Templates

| Флаг | Описание |
| :--- | :--- |
| `-T0` | Параноидально медленно (для IDS) |
| `-T1` | Очень медленно |
| `-T2` | Политесный режим |
| `-T3` | Обычный режим (по умолчанию) |
| `-T4` | Агрессивный (быстро) |
| `-T5` | Максимально быстро (шумно) |

### 8.2. Дополнительные параметры

| Команда | Описание |
| :--- | :--- |
| `--min-rate <num>` | Минимальное количество пакетов в секунду |
| `--max-rate <num>` | Максимальное количество пакетов в секунду |
| `--min-parallelism <num>` | Минимальное количество параллельных запросов |
| `--max-parallelism <num>` | Максимальное количество параллельных запросов |
| `--scan-delay <time>` | Задержка между пакетами |
| `--host-timeout <time>` | Таймаут на хост |

## 💾 9. Сохранение результатов (Output)

| Команда | Описание |
| :--- | :--- |
| `-oN <file>` | Нормальный вывод в текстовый файл |
| `-oX <file>` | XML-формат |
| `-oG <file>` | Grep-формат |
| `-oA <basename>` | Все форматы сразу (XML, нормальный, grep) |

| `--reason` | Показывать причину состояния порта |

## 🚀 10. Готовые команды для HTB и пентеста

### 🔹 Быстрое сканирование всех портов
```bash
nmap -sS -p- -T4 <IP>
```

### 🔹 Детальное сканирование
```bash
nmap -sS -sC -sV -p- -T4 <IP>
```

### 🔹 Агрессивное сканирование
```bash
nmap -A -T4 <IP>
```

### 🔹 Когда хост не отвечает на ping
```bash
nmap -Pn -sS -p- -T4 <IP>
```

### 🔹 Максимально быстрое сканирование (HTB)
```bash
nmap -sS --min-rate 1000 -p- -T4 <IP>
```

### 🔹 Сканирование популярных портов
```bash
nmap -sV -sC -p 21,22,25,80,443,445,1433,3306,3389,8080 <IP>
```

### 🔹 Полный сканер (рекомендуемый для HTB)
```bash
nmap -Pn -sS -p- -sV --version-intensity 8 -O --osscan-guess -T4 <IP>
```

### 🔹 Сканирование подсети
```bash
nmap -sn 10.10.10.0/24
```

## 📊 11. Состояния портов

| Состояние | Значение |
| :--- | :--- |
| `open` | Порт открыт и принимает соединения |
| `closed` | Порт закрыт |
| `filtered` | Порт фильтруется (файрвол, IDS) |
| `unfiltered` | Порт доступен, но неизвестно, открыт ли он |
| `open\|filtered` | Не удаётся определить |
| `closed\|filtered` | Не удаётся определить |
