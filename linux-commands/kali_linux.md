
### 🧭 Навигация по файловой системе

Эти команды помогут вам перемещаться по системе и понимать, где вы находитесь.

| Команда | Описание |
| :--- | :--- |
| `pwd` | Показывает полный путь к текущей директории (Print Working Directory). |
| `ls` | Показывает список файлов и папок в текущей директории. |
| `ls -la` | Показывает **все** файлы, включая скрытые, с подробной информацией (права, владелец, размер). |
| `cd <папка>` | Перейти в указанную папку (Change Directory). |
| `cd ..` | Вернуться на одну папку вверх. |
| `cd ~` | Перейти в вашу домашнюю директорию. |

### 📂 Работа с файлами и папками

Здесь собраны команды для создания, копирования, перемещения и удаления файлов.

| Команда | Описание |
| :--- | :--- |
| `mkdir <имя>` | Создать новую папку (Make Directory). |
| `touch <имя>` | Создать новый пустой файл. |
| `cp <источник> <назначение>` | Копировать файл или папку (Copy). |
| `mv <источник> <назначение>` | Переместить или переименовать файл/папку (Move). |
| `rm <файл>` | Удалить файл (Remove). |
| `rm -r <папка>` | Рекурсивно удалить папку и всё её содержимое (используйте с осторожностью!). |
| `cat <файл>` | Показать содержимое файла на экране (Concatenate). |
| `nano <файл>` | Открыть простой текстовый редактор для редактирования файла. |

### 🛠️ Управление пакетами и обновлениями

Эти команды используются для установки, обновления и удаления программного обеспечения. **Важно:** для их выполнения требуются права суперпользователя, поэтому всегда используйте `sudo` (как в вашем предыдущем вопросе).

| Команда | Описание |
| :--- | :--- |
| `sudo apt update` | **Обновить список доступных пакетов** из репозиториев. Рекомендуется делать это перед установкой нового софта. |
| `sudo apt upgrade` | **Обновить все установленные пакеты** до их последних версий. |
| `sudo apt install <пакет>` | Установить новый пакет или программу. |
| `sudo apt remove <пакет>` | Удалить установленный пакет. |
| `sudo apt search <ключевое_слово>` | Найти пакет по ключевому слову в названии или описании. |

### 🌐 Сетевые команды

Эти команды являются основой для работы в сети и проведения сканирований.

| Команда | Описание |
| :--- | :--- |
| `ifconfig` | Показать информацию о сетевых интерфейсах (IP-адрес, маска и т.д.). В новых системах может потребоваться установка пакета `net-tools`. |
| `ip a` | **Современная альтернатива** `ifconfig`. Показывает IP-адреса и состояние интерфейсов. |
| `ping <хост>` | Проверить связь с удалённым узлом (например, `ping google.com`). |
| `nmap <цель>` | **Мощный инструмент для сканирования сети** и портов. Это одна из визитных карточек Kali Linux. |
| `traceroute <хост>` | Показать маршрут, по которому пакеты идут до удалённого узла. |
| `whois <домен>` | Получить регистрационную информацию о домене. |
| `ssh user@host` | Подключиться к удалённой системе по протоколу SSH (безопасное удалённое управление). |

### ⚙️ Процессы и системная информация

Команды для мониторинга запущенных программ и получения информации о системе.

| Команда | Описание |
| :--- | :--- |
| `ps aux` | Показать список всех запущенных в данный момент процессов. |
| `top` | Показать процессы в реальном времени с обновлением (что-то вроде «Диспетчера задач» в Windows). |
| `kill <PID>` | «Убить» процесс по его ID (PID можно узнать из `ps` или `top`). |
| `whoami` | Показать имя текущего пользователя. |
| `uname -a` | Показать информацию о ядре и операционной системе. |
| `df -h` | Показать использование дискового пространства в удобном для чтения формате. |
| `history` | Показать список ранее введённых команд. |

### 🔑 Права доступа

Эти команды управляют доступом к файлам и папкам.

| Команда | Описание |
| :--- | :--- |
| `chmod <права> <файл>` | Изменить права доступа к файлу (например, `chmod 755 file.sh` сделает скрипт исполняемым). |
| `chown <владелец>:<группа> <файл>` | Изменить владельца и группу файла. |

### 💡 Полезные советы

*   **Автодополнение:** Используйте клавишу `Tab` для автодополнения команд и путей к файлам. Это ускоряет работу и уменьшает количество опечаток.
*   **Справка:** Если вы забыли синтаксис команды, введите `man <команда>` (например, `man ls`), чтобы открыть руководство пользователя. Для выхода нажмите `q`.
*   **История:** Используйте стрелки `Вверх` и `Вниз` на клавиатуре, чтобы перемещаться по истории введённых команд.
*   **`sudo`:** Почти все команды, изменяющие систему, требуют прав суперпользователя. Всегда ставьте `sudo` перед ними.
