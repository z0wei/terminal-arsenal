## 📌 1. Что такое Nmap

**Nmap (Network Mapper)** — инструмент для сетевого сканирования, обнаружения хостов и аудита безопасности. Используется для:

- Обнаружения активных хостов в сети
- Сканирования портов
- Определения ОС и версий сервисов
- Запуска скриптов для поиска уязвимостей (NSE)

---

## 🎯 2. Базовый синтаксис

```bash
nmap [параметры] <цель>
```

---

## 📍 3. Выбор цели

| Команда | Описание |
| :--- | :--- |
| `nmap 192.168.1.1` | Сканирование одного IP |
| `nmap domain.com` | Сканирование домена |
| `nmap 192.168.1.1-254` | Диапазон IP |
| `nmap 192.168.1.0/24` | Подсеть |
| `nmap -iL targets.txt` | Из файла |
| `nmap -n <target>` | Без DNS-разрешения (быстрее) |

---

## 🔍 4. Обнаружение хостов (Host Discovery)

| Команда | Описание |
| :--- | :--- |
| `nmap -sn <target>` | Только обнаружение хостов (без портов) |
| `nmap -Pn <target>` | Пропустить проверку ping |
| `nmap -PS<port> <target>` | TCP SYN ping |
| `nmap -PA<port> <target>` | TCP ACK ping |
| `nmap -PU<port> <target>` | UDP ping |
| `nmap -PE <target>` | ICMP Echo ping |

## 🚪 5. Сканирование портов (Port Scanning)

### 5.1 Типы TCP-сканирования

| Флаг | Название | Описание |
| :--- | :--- | :--- |
| `-sS` | SYN Scan (Stealth) | Полуоткрытое сканирование. **По умолчанию** |
| `-sT` | TCP Connect Scan | Полное TCP-рукопожатие (без root) |
| `-sA` | ACK Scan | Определение фильтров |
| `-sF` | FIN Scan | Отправляет FIN-флаг |
| `-sN` | Null Scan | Пакеты без флагов |
| `-sX` | Xmas Scan | FIN, URG, PSH флаги |

### 5.2 UDP-сканирование

| Команда | Описание |
| :--- | :--- |
| `nmap -sU <target>` | UDP-сканирование |
| `nmap -sU -p 53,161,67,69 <target>` | Распространённые UDP-порты (DNS, SNMP, DHCP, TFTP) |

### 5.3 Выбор портов

| Команда | Описание |
| :--- | :--- |
| `-p 80,443` | Указанные порты |
| `-p 1-65535` | Диапазон |
| `-p-` | Все порты (1-65535) |
| `-F` | Только 100 самых популярных |
| `--top-ports 200` | 200 самых популярных |

## 🖥️ 6. Обнаружение версий и ОС

| Команда | Описание |
| :--- | :--- |
| `nmap -sV <target>` | Определение версий |
| `nmap -sV --version-light <target>` | Лёгкое (быстрее) |
| `nmap -sV --version-all <target>` | Полное (медленнее) |
| `nmap -O <target>` | Определение ОС |
| `nmap -A <target>` | **Всё в одном:** ОС + версии + скрипты + traceroute |

## 📜 7. Nmap Scripting Engine (NSE)

### 7.1 Основные флаги

| Команда | Описание |
| :--- | :--- |
| `-sC` | Стандартные скрипты |
| `--script <script>` | Конкретный скрипт |
| `--script <category>` | Все скрипты категории |
| `--script-help <script>` | Справка по скрипту |

### 7.2 Категории скриптов

| Категория | Описание |
| :--- | :--- |
| `default` | Безопасные скрипты по умолчанию |
| `safe` | Безопасные (не наносят вред) |
| `enumeration` | Сбор информации |
| `auth` | Проверка аутентификации |
| `brute` | Брутфорс паролей |
| `exploit` | Эксплуатация уязвимостей |
| `vuln` | Поиск уязвимостей |

**Примеры:**
```bash
nmap --script http-enum <target>
nmap --script smb-enum-shares <target>
nmap --script vuln <target>
```

## 🛡️ 8. Обход файрволов и IDS (Evasion)

| Команда | Описание |
| :--- | :--- |
| `-Pn` | Пропустить ping |
| `-f` | Фрагментация пакетов |
| `-D RND,RND,ME` | Случайные декои |
| `-D 10.10.10.1,ME` | Конкретные декои |
| `-S <IP>` | Спуфинг IP |
| `--spoof-mac <MAC>` | Спуфинг MAC |
| `--proxies <proxy>` | Через прокси |
| `--scan-delay <time>` | Задержка между пакетами |
| `-6` | IPv6 (часто менее мониторится) |

**Пример:**
```bash
nmap -Pn -f -D RND,RND,ME -F <target>
```

## ⏱️ 9. Настройка скорости (Timing)

### Timing Templates

| Флаг | Скорость |
| :--- | :--- |
| `-T0` | Параноидально медленно |
| `-T1` | Очень медленно |
| `-T2` | Политесный |
| `-T3` | Обычный **(по умолчанию)** |
| `-T4` | Агрессивный |
| `-T5` | Максимально быстро |

### Дополнительные параметры

| Команда | Описание |
| :--- | :--- |
| `--min-rate 1000` | Минимум пакетов/сек |
| `--max-rate 10` | Максимум пакетов/сек |
| `--host-timeout 5m` | Таймаут на хост |
| `--scan-delay 1s` | Задержка между пакетами |

## 🚀 11. Готовые команды для HTB

```bash
# Быстрое сканирование всех портов
nmap -sS -p- -T4 <IP>

# Максимально быстро
nmap -sS --min-rate 1000 -p- -T4 <IP>

# Детальное сканирование
nmap -sV -p 21,22,80 <IP>

# Полное агрессивное
nmap -A -T4 <IP>

# Когда хост не отвечает на ping
nmap -Pn -sS -p- -T4 <IP>

# Комбинированное (рекомендую)
nmap -Pn -sS -p- -sV --version-intensity 8 -O --osscan-guess -T4 <IP>
```

## 📊 12. Состояния портов

| Состояние | Значение |
| :--- | :--- |
| `open` | Порт открыт |
| `closed` | Порт закрыт |
| `filtered` | Фильтруется (файрвол) |
| `unfiltered` | Доступен, статус неизвестен |
| `open\|filtered` | Не удаётся определить |
| `closed\|filtered` | Не удаётся определить |
