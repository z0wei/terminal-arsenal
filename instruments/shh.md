## 📌 1. Что такое SSH

**SSH (Secure Shell)** — это криптографический сетевой протокол для удалённого управления системами, передачи данных и создания защищённых туннелей.

### Основные компоненты:
| Компонент | Описание |
| :--- | :--- |
| **ssh** | Клиент для подключения к удалённым хостам |
| **sshd** | Демон сервера, который принимает подключения |
| **scp** | Копирование файлов через SSH |
| **sftp** | Интерактивная передача файлов |
| **ssh-keygen** | Генерация ключевых пар |

---

## 🔑 2. Основные команды подключения

### ✅ Базовое подключение
```bash
ssh user@host
```

### ✅ Подключение с указанием порта
```bash
ssh -p 2222 user@host
```

### ✅ Подключение с ключом
```bash
ssh -i private_key.pem user@host
```

### ✅ Выполнение одной команды без интерактивной сессии
```bash
ssh user@host "ls -la"
```

### ✅ Подключение с отладкой (verbose)
```bash
ssh -v user@host
ssh -vv user@host      # ещё подробнее
ssh -vvv user@host     # максимальная детализация
```

---

## 🎯 3. Ключи и параметры

| Флаг | Описание |
| :--- | :--- |
| `-p <port>` | Указать порт (по умолчанию 22) |
| `-i <keyfile>` | Использовать конкретный приватный ключ |
| `-l <user>` | Указать имя пользователя |
| `-v` | Подробный вывод (отладка) |
| `-q` | Тихий режим (подавляет предупреждения) |
| `-C` | Включить сжатие (ускоряет передачу) |
| `-4` | Использовать IPv4 |
| `-6` | Использовать IPv6 |
| `-o <option>` | Передать опцию (например, `-o StrictHostKeyChecking=no`) |
| `-N` | Не выполнять команды (для форвардинга) |
| `-f` | Фоновый режим после аутентификации |
| `-T` | Отключить псевдо-терминал (для скриптов) |
| `-X` | Включить X11-форвардинг (GUI-приложения) |
| `-A` | Агент-форвардинг (проброс ssh-agent) |
| `-J <jump>` | Подключение через промежуточный хост (Jump Host) |

## 🔐 4. Аутентификация по ключам

### 4.1 Генерация ключевой пары
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
ssh-keygen -t ed25519 -a 100 -C "your_email@example.com"
```

### 4.2 Копирование публичного ключа на сервер
```bash
ssh-copy-id user@host
```
### 4.3 Ручное копирование ключа
```bash
cat ~/.ssh/id_rsa.pub | ssh user@host "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

### 4.4 Защита ключа (парольная фраза)
```bash
ssh-keygen -p -f ~/.ssh/id_rsa
```

### 4.5 Управление ключами через ssh-agent
```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa
ssh-add -l        # список добавленных ключей
```

## 📂 5. Передача файлов (SCP / SFTP)

### 5.1 SCP — Secure Copy Protocol

```bash
# Копирование локального файла на сервер
scp file.txt user@host:/path/to/destination/

# Копирование с сервера локально
scp user@host:/path/to/remote/file.txt /local/destination/

# Копирование с ключом
scp -i key.pem file.txt user@host:/path/

# Копирование через другой порт
scp -P 2222 file.txt user@host:/path/

# Копирование папки рекурсивно
scp -r folder/ user@host:/path/
```

### 5.2 SFTP — Interactive File Transfer

```bash
sftp user@host
sftp -P 2222 user@host
sftp -i key.pem user@host
```

**Команды внутри SFTP:**
| Команда | Описание |
| :--- | :--- |
| `ls` | Список файлов |
| `cd` | Смена директории |
| `put file.txt` | Загрузить файл |
| `get file.txt` | Скачать файл |
| `mkdir folder` | Создать папку |
| `rm file.txt` | Удалить файл |
| `exit` / `quit` | Выход |

## 🔀 6. SSH-туннели (Port Forwarding)

### 6.1 Локальный форвардинг (Local Forwarding)

Пробрасывает порт с удалённого хоста на локальный.

```bash
ssh -L 8080:localhost:80 user@host
```
Теперь локальный порт 8080 ведёт на порт 80 удалённого хоста.

### 6.2 Удалённый форвардинг (Remote Forwarding)

Пробрасывает локальный порт на удалённый хост.

```bash
ssh -R 9090:localhost:80 user@host
```
Теперь на удалённом хосте порт 9090 ведёт на твой локальный порт 80.

### 6.3 Динамический форвардинг (Dynamic / SOCKS Proxy)

Создаёт SOCKS-прокси для маршрутизации трафика через SSH.

```bash
ssh -D 1080 user@host
```
Теперь можно настроить браузер на SOCKS-прокси `127.0.0.1:1080`.

## 🚀 7. Использование SSH как прокси

### Через `.ssh/config`
```bash
Host target
    ProxyJump user@jump-host
```
### Через `-J` (Jump Host)
```bash
ssh -J user@jump-host user@target
```

### Переадресация через `ssh -W`
```bash
ssh -W target:22 user@jump-host
```

## ⚡ 8. Ускорение и оптимизация

### Включить сжатие
```bash
ssh -C user@host
```

### Отключить проверку DNS
```bash
ssh -o UseDNS=no user@host
```

### Поддержание соединения живым
```bash
ssh -o ServerAliveInterval=60 user@host
```

### Отключить проверку хост-ключа (для скриптов)
```bash
ssh -o StrictHostKeyChecking=no user@host
```

## 🛡️ 9. Безопасность и защита

### 9.1 Отключение парольной аутентификации (только ключи)
```bash
sudo nano /etc/ssh/sshd_config
# Установить:
PasswordAuthentication no
PubkeyAuthentication yes
```

### 9.2 Изменение порта SSH
```bash
Port 2222
```

### 9.3 Запрет root-логина
```bash
PermitRootLogin no
```

### 9.4 Ограничение пользователей
```bash
AllowUsers user1 user2
DenyUsers root
```

### 9.5 Отключение X11-форвардинга
```bash
X11Forwarding no
```

### 9.6 Ограничение попыток аутентификации
```bash
MaxAuthTries 3
```

## 🧠 10. Устранение неполадок

| Проблема | Решение |
| :--- | :--- |
| `Connection refused` | Сервер не слушает порт / файрвол |
| `Permission denied` | Неверный пароль / ключ |
| `Host key verification failed` | Изменился ключ хоста → удалить из `~/.ssh/known_hosts` |
| `Connection timed out` | Хост недоступен / блокировка |
| `ssh: command not found` | Установи OpenSSH-client |
| `Agent admitted failure to sign` | Перезапустить `ssh-add` или `ssh-agent` |
